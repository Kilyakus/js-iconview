# IconView.js - v1.2610.03507

It acts as a single icon source for the stack: built-in names, SVG markup, URLs, Font Awesome classes, glyphs and DOM nodes are turned into vector, raster, procedural or glyph artwork and can be rendered as an SVG string, a data-URI image or a ready DOM node.
